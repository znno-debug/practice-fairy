# 🧚‍♀️ 연습요정 - 예체능 선생님을 위한 과외노트 & 출석 리포트

**연습요정**은 음악(피아노, 바이올린, 보컬 등) 및 예체능 과외 선생님을 위한 올인원 과외 관리 및 학부모 안심 웹 리포트 솔루션입니다.

---

## 🌟 주요 기능

1. **선생님 프로필 & 수강료 입금 계좌 설정**
   - 선생님 성함, 전공/지도 분야, 프로필 약력 관리
   - 수강료 입금 계좌(은행명, 계좌번호, 예금주) 등록
   - 학부모 알림장 및 결제 안내장에 실시간 연동

2. **🧚‍♀️ 학생 전용 연습실 & 루틴 트래커**
   - **오늘 누적 연습 세션 타임라인**:
     - 하루 총 연습량(분) 및 완료 세션 수 자동 계산
     - 시간대별 연습 피드 (예: *16:00 ~ 16:20 하농 No.5, 16:25 ~ 16:50 모차르트 소나타*)
     - 실시간 세션 타이머(`▶ 연습 시작`) 및 수동 세션 기록 지원
   - **일일 연습 체크리스트**: 선생님이 레슨노트에 적어준 과제가 학생의 일일 체크리스트로 자동 배정, 학생 자율 목표 추가 가능
   - **다음 수업 질문 보관함**: 집에서 연습하다 생긴 의문점(운지, 박자, 페달 등)을 적어두면 선생님의 다음 수업 작성창에 알림 표시
   - **정밀 멀티박자 메트로놈**:
     - 2/4, 3/4, 4/4 박자 및 **6/8박자** 지원 (첫 박 강세 및 6/8박자 4박 보조 강세 적용)
     - 비트 램프 시각화 애니메이션
     - 별도 메트로놈 앱 사용자를 위한 **'접기/펼치기'** 지원
   - **연습 스트릭 & 칭찬 트로피 전당**: 연속 연습 일수(Streak) 표시 및 선생님의 칭찬 뱃지 모음으로 연습 동기부여 극대화

3. **수강권 회차 관리 (4회 / 8회 / 12회 + 직접 입력)**
   - 신규 학생 등록 시 4회, 8회, 12회 원클릭 프리셋 및 직접 입력 지원
   - 학생별 월 수업료(레슨비) 금액 설정
   - 출석 시 잔여 회차 자동 차감 및 충전 모달(+4/+8/+12/직접충전)

3. **학부모 다음 달 수강료 납부 요청 시스템**
   - **수강료 만료 임박 알림**: 잔여 수강권 1회 이하 시 알림 배지 및 청구 버튼 활성화
   - **카톡 전송용 정중한 안내 문구 원클릭 복사**: 학생명, 회차, 수업료, 입금 계좌 자동 완성
   - **학부모 웹 리포트 안심 결제 카드 (`share.html`)**:
     - 다음 달 등록 회차 및 수업료 표시
     - 입금 계좌번호 **[원클릭 복사]** 버튼으로 토스/은행 앱 송금 유도

4. **수업 캘린더 & 스마트 출석체크 (월간 / 주간 뷰 전환 지원)**
   - **📅 월간 / 📆 주간 뷰 원클릭 토글 스위치**:
     - **월간 뷰 (기본값)**: 한 달 전체(1일~말일)의 수업 분포와 출결 현황을 넓은 그리드로 조망
     - **주간 뷰**: 이번 주(일~토) 요일별 수업 스케줄(시간, 학생명, 출결 칩)을 타임테이블 카드로 한눈에 확인
     - 선택한 모드는 브라우저에 자동 저장되어 다음 접속 시에도 그대로 유지
   - **이전/다음 탐색**: 월간 모드에서는 1개월 단위, 주간 모드에서는 1주일 단위로 스마트 전환
   - **5단계 출결 상태 원클릭 변경**:
     - 🟢 **출석**: 정상 수업 출석 및 수강권 회차 카운트
     - 🔴 **결석**: 결석 처리
     - 🔵 **보강**: 보강 수업 표시
     - ⚪ **스킵**: 방학/휴일/시험기간 등 수업 스킵
     - 🟣 **기타(직접 입력)**: "학교 시험", "콩쿠르/대회", "병원/독감" 등 사유 직접 입력 & 빠른 칩
   - 캘린더 일자별 컬러 인디케이터 도트 표시 및 우측 당일 스케줄 관리 패널 연동

5. **음악/예체능 특화 레슨 노트**
   - 진도곡, 테크닉, 지도 포인트 및 칭찬 뱃지
   - **유튜브 링크 첨부**: 서버 비용 **0원** (유튜브 '일부 공개'로 업로드 시 학부모에게만 안전 재생)
   - 다음 레슨까지 가정 연습 가이드

6. **학부모 안심 공유 리포트 (`share.html`)**
   - **별도 앱 설치 및 로그인 불필요**: 카카오톡 등으로 전송 가능한 다이렉트 URL 제공
   - 모바일 카드 뷰: 유튜브 연주 영상 재생, 선생님 피드백, 이번 달 잔여 수강권 게이지, 수강료 청구 카드, 확인 스탬프

7. **📲 스마트폰 홈 화면 PWA(Progressive Web App) 앱 설치 & 고해상도 아이콘**
   - **앱스토어 다운로드 없이 1초 설치**: Safari 또는 Chrome에서 "홈 화면에 추가" 한 번으로 네이티브 앱처럼 동작
   - **완벽한 PWA 규격 탑재**:
     - `manifest.json`: 독립형 풀스크린 모드(`display: standalone`), 테마 컬러, 반응형 아이콘
     - `sw.js` (Service Worker): 오프라인 캐싱 지원 (통신이 약한 지하 방음 연습실에서도 원활히 구동)
     - 고해상도 앱 아이콘 팩 탑재 (`icons/` 폴더 내 192x192, 512x512, Maskable, Apple Touch Icon)
   - **기기별 맞춤형 설치 안내 모달**:
     - 아이폰(iOS Safari): 하단 공유 버튼(⎋) -> '홈 화면에 추가' 3단계 가이드
     - 안드로이드(Chrome): 원클릭 네이티브 설치 다이얼로그 연동
     - PC/Mac: 주소창 우측 설치 버튼으로 독립 창 데스크톱 앱 지원

---

## 🚀 로컬 실행 방법

터미널에서 아래 명령어로 서버를 띄워 테스트할 수 있습니다:

```bash
python3 server.py
```
* 브라우저에서 `http://localhost:8080/index.html`이 자동으로 열립니다.
* 상단 우측의 **`📲 홈 화면에 앱 설치`** 버튼을 누르면 기기별 설치 방법을 즉시 확인하고 설치할 수 있습니다.
* 또는 Finder에서 `index.html`을 더블 클릭하여 바로 열 수 있습니다.
