> 사용법: 새 세션을 열고 아래 "지시문" 블록 전체를 붙여 넣는다.
> 이 작업은 **한 세션에서 순서대로** 진행한다(오케스트레이션 불필요 — 이유는 맨 아래).

## 지시문

```
CONTEXT.md를 먼저 읽고, 남은 작업 ⑩ "학부모 연결: 링크 + 앱 이원 운영"의 1단계를 진행해줘.
0단계(공유 리포트 보안, 4장 6번)는 끝났고, 그 보안 원칙을 1단계에도 똑같이 적용해.

## 배경 (기획 결정 요약)
- 워킹맘 학부모 피드백: 아이가 여러 레슨을 듣는데 남은 횟수·납부 시점을 엄마가 알 수 없고,
  선생님도 물어보면 그제서야 스케줄러를 뒤져서 센다.
- GPS·QR 출석은 하지 않기로 결정했다. 출석은 지금처럼 선생님이 누른다.
- 최종 목표는 앱스토어 앱이다. 학부모는 두 가지 방법으로 쓴다.
  · 링크: 가입 없이 이 수업의 "현재 상태"를 본다.
  · 앱 가입: 여러 선생님 수업을 한 화면에서 보고 푸시 알림을 받는다. (2~4단계, 이번 범위 아님)
- 원칙: 데이터는 하나, 보는 창은 두 개. 링크를 일부러 불편하게 만들지 않는다.
  1단계 구조는 나중에 앱 가입(3단계)으로 그대로 이어질 수 있게 설계한다.

## 0단계: 공유 리포트 보안 수정 — 완료 (2026-11-27, v35)
- 할 일 없음. 단, 1단계의 학부모 고정 링크도 같은 원칙을 따른다:
  테이블 직접 공개 금지, 토큰 1개로 1건만 주는 RPC(get_shared_report 방식), 추측 불가 토큰.

## 1단계: 학생별 고정 학부모 링크
- 선생님이 수강생 화면에서 [학부모 링크]를 만들어 카톡으로 한 번 보낸다.
  학부모가 언제 열든 최신 상태가 보인다.
- 링크 화면에 들어갈 것:
  · 남은 횟수 / 전체 횟수
  · 다음 수업 일정
  · 납부 시점 안내(잔여 0~1회일 때 강조) + 계좌 복사 (계좌가 비어 있으면 '선생님께 문의')
  · 최근 출결 몇 건(5대 출결 표기)
  · 최근 레슨 노트 요약
- 넣지 말 것: 선생님 내부 메모, 다른 학생 정보, 수강료 금액 외의 선생님 개인 정보.
- 선생님이 할 수 있어야 하는 것:
  · 링크 끄기
  · 새 링크 재발급 (예전 링크는 즉시 무효)
  · 학생을 삭제하면 링크도 함께 삭제 (기존 deleteStudent 흐름에 연결)
- 데이터 전달 방식은 두 안을 비교해서 하나를 추천하고, 내 확인을 받은 뒤 구현해줘.
  (A) 선생님 앱이 출석·노트 저장 때마다 학생별 요약을 별도 테이블에 갱신
  (B) 토큰으로 실제 테이블을 읽는 RPC
  비교 기준: 보안, 오프라인/동기화 지연, 나중에 학부모 계정(3단계)으로 확장하기 쉬운지.
- 기존 레슨 리포트 공유(sendKakaoReportCard, 노트 1건 스냅샷)는 그대로 둔다.
  고정 링크는 별도 기능이다. 카카오 카드로 보낼 수 있으면 재사용한다.

## 작업 규칙

  출석 1회 처리 → 링크 새로고침 시 잔여 횟수 반영 → 링크 끄기 후 열리지 않음.
  모바일 폭(375px)도 확인한다.
- 설명은 기획자에게 하듯 쉬운 서비스 언어로 해줘.
- 커밋은 단계별로 나눠서 하되, 푸시 전에 나에게 확인받아줘.
```

## 오케스트레이션(Orca)을 쓰지 않는 이유

- **순서가 정해진 작업이다**: 0단계(보안) → 1단계(데이터 방식 결정) → 화면 순서다.
  각 단계가 앞 단계의 결과에 의존해서 동시에 돌릴 부분이 거의 없다.
- **같은 파일을 건드린다**: 앱 로직이 거의 `index.html` 한 파일과 `supabase_schema.sql`에 몰려 있다.
  여러 작업자가 동시에 고치면 충돌만 늘어난다.
- **중간에 결정이 필요하다**: 데이터 방식(A/B)은 사용자 확인을 받고 진행해야 한다.

### 나중에 Orca가 맞는 시점
2단계(앱 포장)부터는 서로 독립된 일이 생긴다. 그때 나눠 맡기면 된다.
- 작업자 1: Capacitor로 iOS/Android 프로젝트 만들기 + 빌드 확인 (새 폴더, 기존 파일 거의 안 건드림)
- 작업자 2: Apple 로그인 콘솔 설정 가이드 `docs/apple_login_setup.md` 작성 (문서만)
- 작업자 3: 유니버설 링크·앱 링크 설정 파일과 가이드 (`.well-known/` 등)

그 시점의 지시문 예시:
```
/orchestration CONTEXT.md 남은 작업 ⑩의 2단계(앱 포장)를 Orca 작업자 3명에게 나눠줘:
(1) Capacitor iOS/Android 프로젝트 생성·빌드, (2) Apple 로그인 설정 가이드 문서,
(3) 유니버설 링크/앱 링크 설정. 각자 맡은 파일만 수정하고, 끝나면 결과를 모아서
충돌 없이 합칠 수 있는지 확인한 뒤 나에게 보고해줘.
```
