# 🧚‍♀️ 연습요정 (Practice Fairy) — 1:1 음악 레슨 관리 & 학부모 리포트 PWA

**연습요정**은 음악(피아노, 바이올린, 보컬 등) 1:1 레슨 선생님을 위한 **출결·수강료·레슨노트 관리 및 수강생 연습일지 PWA**입니다.
수강료 누락을 막고 재등록률을 높이는 레슨 프로페셔널 패키지를 지향하며, 학부모와 성인 수강생에게는 별도 앱 설치나 로그인 없이 바로 열람할 수 있는 1:1 리포트(`share.html`)를 제공합니다.

- **배포 URL (GitHub Pages)**: https://znno-debug.github.io/practice-fairy/

---

## 🌟 주요 기능

1. **선생님 계정 로그인 & 클라우드 실시간 동기화 (Supabase)**
   - **Supabase Auth** 이메일/비밀번호 로그인 지원 (유저별 데이터 격리)
   - 선생님 프로필, 수강생, 수업 일정, 레슨 노트, 연습 체크리스트, 질문, 연습 세션 등 7개 테이블 실시간 클라우드 동기화
   - JSON 전체 데이터 백업 다운로드(`📥`) 및 복원(`📤`) 지원
   - 선생님 입금 계좌(은행명, 계좌번호, 예금주) 등록 및 수강료 안내 자동 연동

2. **수업 캘린더 & 5대 출결 체계 (월간 / 주간 뷰 지원)**
   - **월간 / 주간 뷰 원클릭 전환** (선택 모드 자동 저장)
   - **5대 출결 체계**:
     - `출석` (-1회 차감)
     - `당일취소` (-1회, 규정 차감)
     - `결석` (0회 차감, 보강 대기 위젯에 자동 연동)
     - `순연` (0회 차감, 사전 연기)
     - `보강` (-1회 차감)
   - **보강 대기 위젯**: 결석 학생만 모아 보강 일정을 빠르게 잡을 수 있는 대시보드 위젯

3. **수강권 회차 관리 & 수강료 골든타임 안내**
   - 4회 / 8회 / 12회 프리셋 및 직접 입력 지원, 학생별 월 수업료 설정
   - **수강료 골든타임 모달**: 잔여 수강권이 0~1회가 되면 자동으로 안내 모달이 뜨고, 입금 계좌가 포함된 정중한 안내문을 자동 완성해 Web Share API로 즉시 공유

4. **음악/예체능 특화 레슨 노트 & 카카오톡 1:1 리포트 (`share.html`)**
   - 진도곡, 테크닉, 지도 포인트, 칭찬 배지, 가정 연습 과제, 유튜브 링크 첨부
   - **카카오톡 피드 카드 공유 (`Kakao.Share.sendDefault`)** 및 단축 리포트 스냅샷(`fairy_shared_reports_v1`) 지원
   - **학부모/수강생 비로그인 열람**: 카톡에서 링크를 누르면 앱 설치·회원가입 없이 모바일 카드 뷰로 오늘의 레슨 내용, 잔여 회차, 입금 계좌 원클릭 복사 확인 가능

5. **🧚‍♀️ 마이 연습실 & 루틴 트래커**
   - 오늘 누적 연습 세션 타임라인(실시간 타이머 & 수동 기록)
   - 일일 연습 체크리스트 & 다음 수업 질문 보관함
   - 2/4, 3/4, 4/4, 6/8 정밀 멀티박자 메트로놈(Web Audio API)
   - 연속 연습 스트릭(Streak) & 칭찬 트로피

6. **📲 PWA (Progressive Web App) 앱 설치 & 오프라인 지원**
   - `manifest.json` 및 `sw.js`(Service Worker) 기반 홈 화면 설치 및 오프라인 캐싱 지원
   - iOS Safari / Android Chrome / 데스크톱 브라우저별 설치 가이드 제공

## 📁 주요 파일 구성

- `index.html`: 메인 앱 (캘린더, 레슨 노트, 수강생 관리, 마이 연습실, Auth, Supabase 동기화, 카카오 공유)
- `share.html`: 학부모/수강생용 1:1 리포트 페이지 (비로그인 열람)
- `sw.js` / `manifest.json` / `icons/`: PWA 서비스 워커, 매니페스트 및 아이콘 자산
- `supabase_schema.sql`: Supabase 테이블 생성 및 유저별 RLS 보안 정책 SQL
- `build_icons.py`: PWA·파비콘 아이콘 생성 스크립트
- `server.py`: 로컬 테스트용 HTTP 서버

---

## 🚀 로컬 실행 방법

터미널에서 아래 명령어로 로컬 서버를 실행할 수 있습니다:

```bash
python3 server.py
```

* 브라우저에서 `http://localhost:8080/index.html`이 열리며, 같은 Wi-Fi 모바일 기기 접속용 IP도 함께 표시됩니다.
* 클라우드 DB를 새로 세팅할 경우 `supabase_schema.sql` 전체 내용을 Supabase Dashboard의 SQL Editor에서 실행하세요.
